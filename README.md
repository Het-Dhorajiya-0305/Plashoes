## Plashoes 🛒

**Plashoes** is a full-stack eCommerce website built to provide a seamless online shopping experience for footwear.  
It allows users to browse, search, and purchase shoes online while offering an admin dashboard for managing products, orders, and users.

## Features

- **Product Catalog** – Browse a variety of footwear with detailed descriptions, prices, and images.
- **Shopping Cart** – Add, update, and remove products with a live cart view.
- **Secure Checkout** – Pay with **Stripe payment gateway** for safe transactions.
- **User Accounts** – Sign up, log in, and manage profile information.
- **Google OAuth Login** – Quick and secure authentication using Google.
- **Order Tracking** – View past orders and check current order status.
- **Admin Dashboard** – Manage products, categories, orders, and users.
- **Responsive UI** – Works on desktops, tablets, and mobile devices.
- **Global State with Context API** – Share state across components without prop drilling.

## Tech Stack

### Frontend
- **React + Vite** – Modern, fast UI framework
- **CSS** – Custom styling for a unique look
- **React Context API** – Global state management for authentication, cart, and user data
- **Axios** – API requests
- **Stripe.js** – Payment integration

### Backend
- **Node.js + Express** – REST API server
- **MongoDB + Mongoose** – Database for products, users, and orders
- **JWT** – Secure authentication
- **Google OAuth 2.0** – Login via Google accounts
- **bcrypt** – Password encryption
- **Stripe API** – Payment gateway
- **dotenv** – Environment configuration
